# Snake Game

A browser-based Snake game built with HTML, CSS, and JavaScript.

## How to Run

Open [index.html](./index.html) in a web browser. No build tools or dependencies are required.

## How to Play

1. Click **Start Game**.
2. Use the arrow keys to control the snake.
3. Eat the red food to grow and increase your score.
4. Press **Space** or click **Pause** to pause and resume.
5. Click **Restart Game** to start a new round.

The game ends when the snake touches the border or its own body.

## Features

- Score and persistent high score using `localStorage`
- Food never spawns on the snake
- Increasing speed as the score rises
- Start, pause, resume, and restart controls
- Visual styling for the game board, snake, food, and game-over state

## Project Files

- `index.html` - Page structure
- `style.css` - Game styling
- `script.js` - Game logic
